# Spec Decisions (ADRs)

Resolved build decisions land here as `<NNN>-<slug>.md`, recording each decision from CLAUDE.md's "Build decisions" list as a proposed FIRST. Line.

- Full template: `../templates/decision.md`
- Workflow: when a decision is resolved, write the ADR, then update the "Build decisions" section of CLAUDE.md and mark the decision as resolved there.
